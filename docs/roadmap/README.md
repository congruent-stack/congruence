# Roadmap

## Current MVP

- Local workspaces with optional repository references.
- Agent activity published through MCP, with persistent status and summaries.
- A minimal dark dashboard for viewing and filtering work.
- Workspace-specific React dashboards with managed Node/TypeScript backends, published through MCP.
- Reviewed dashboard commands, existing-activity messaging, and prepared native Desktop prompts.

## Future direction

- Centralized notifications and a knowledge/context vault.
- Richer harness connections, including session links where supported.
- Remote access, multiple users, and shared workspaces when productization is requested.

Choose the next small addition from actual use; these directions have no fixed order or delivery dates.
