# Vision

Congruence gives software engineers one place to understand work spread across projects, repositories, agents, and communication tools. It should make progress, results, and relevant context easy to find.

## Principles

- **Built for humans.** Keep the dashboard quiet, readable, and useful with little interaction. Prefer a minimal dark interface.
- **Complement existing harnesses.** Coding and agent execution stay in tools such as Codex and Claude. Agents can publish updates here; humans return to the source tool when needed.
- **Start small.** Build useful local capabilities before adding platform infrastructure. Keep documentation brief and the roadmap focused on direction.
- **Use free, open-source dependencies.** Running the dashboard should not require a paid service.

The longer-term direction is remote access with multiple users and shared workspaces. Productization will happen when explicitly requested.
